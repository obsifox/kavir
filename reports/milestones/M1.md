# Milestone M1 — walking skeleton: COMPLETE (2026-10-26)

Goal (ADR-005 v3): `fn main() -> i32 { return 42; }` must flow
lexer -> parser -> checker -> IR -> x86-64 encoder -> static ELF, and the
binary must exit 42. No libc, no cc/as/ld anywhere in the compiled-program
path (ADR-002 v2). Includes amendment (b) from day one: IR interpreter
cross-check + sanitizer fuzz over the frontend.

## What was built

- `compiler/src/lexer.c` — tokens with file:line:col spans, `//` comments.
- `compiler/src/parser.c` — M1 grammar (fn/main/return/int literal),
  honest "arrives in M2/M3" diagnostics beyond it.
- `compiler/src/check.c` — M1 rules: single `main` returning i32, literal
  range check, return-last, duplicate names.
- `compiler/src/ir.c` — IR construction (`IR_CONST`/`IR_RET` over virtual
  registers) + text dump (`kavir dump-ir`).
- `compiler/src/interp.c` — IR interpreter: the reference semantics;
  `kavir interp` exits with main's value (amendment b).
- `compiler/src/target_x86_64_linux.c` — the WHOLE x86-64/Linux coupling
  (opcodes, SysV register choice, exit_group=231, load base 0x400000,
  ELF64 fields) in ONE module per the ADR-006 discipline rule. Direct
  machine-code emission + internal static ET_EXEC ELF writer
  (one R+X PT_LOAD, no section headers), `_start` = call main; exit_group.
- `compiler/tests/run.sh` — conformance: ELF vs interpreter comparison
  (amendment b) + negative tests with span diagnostics + IR dump smoke.
- `compiler/scripts/fuzz.py` — mutation fuzzer over lexer/parser/checker/
  codegen under ASan+UBSan (`make kavir-asan`, amendment b).

## Design decisions taken inside M1 (all reversible, none one-way)

- Exit path: `_start` calls `main`, takes EAX, `exit_group(231)` — no
  libc, matches ADR-002 v2. (Alternative considered: inline exit in
  main's lowering — rejected, pollutes every function's codegen.)
- Binary layout: single R+X PT_LOAD at 0x400000, no section headers
  (kernel does not need them); RW segment arrives with M2 data.
- M1 codegen lowering is a documented special case (single live value in
  EAX); generalization is M2/M3 work, not hidden complexity.
- IR register model: virtual registers now, trivial mapping in M1.
- No new irreversible decision was reached; nothing needed a user stop
  per the M1 authorization (ADR-005 v3 status line).
